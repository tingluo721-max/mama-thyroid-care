🔥 甲亢与手术（术前怎么处理）

她是亚临床甲亢（T3/T4 正常、仅 TSH 压低）——风险比临床甲亢低，但 TSH 完全抑制 + 高血压/脑梗，术前仍需准备：

  • 控制心率：β受体阻滞剂（普萘洛尔/倍他乐克），静息心率 < 90 次/分
  • 可能短程抗甲状腺药（甲巯咪唑），确保 FT3/FT4 术中被刺激也不飙高
  • 术前复查甲功：FT3/FT4 正常 + 心率达标即可手术（TSH 不必等回升）
  • 麻醉科/心内科会诊：评估心血管风险

🟢 亚临床甲亢准备通常 1–2 周即可；且甲亢很可能是毒性结节所致，切掉结节 = 甲亢病根一起除掉，术后甲亢自然缓解。

🧠 总览：为什么叫"懒癌"

甲状腺癌是预后最好的实体瘤之一，尤其乳头状癌 10 年生存率 >95%。但"懒"≠"不用管"：一旦有淋巴结转移，必须规范手术清干净。妈妈已确诊乳头状癌 + 左颈 III/IV 区淋巴结转移（Ⅱ期），正处在"必须认真处理"的关键节点——只要首台手术做得规范彻底，预后依然非常好。

📐 TNM 分期（AJCC 第8版）

妈妈 60 岁，用 55 岁以上分期：T2（3.4cm）+ N1b（侧颈转移）+ M0 → Ⅱ期。甲状腺癌里"有淋巴结转移"很常见，Ⅱ期依然是治愈率很高的分期，不是晚期没救。

🔪 手术方案

  • 全切：有侧颈淋巴结转移 = 全切硬指征
  • 中央区（VI区）清扫：常规做（转移第一站）
  • 侧颈清扫（II–V区）：因 III/IV 区转移（已确诊），做治疗性清扫，重点是 III/IV 区
  • 清得干净，复发率直线下降——所以排医生时把"侧颈清扫经验"放第一

💊 术后治疗

  • 优甲乐：全切后终身替代 + TSH 抑制治疗，便宜、副作用小
  • 放射性碘（碘131）：中高危才做，是否做看术后风险分层
  • 靶向药：仅晚期/难治，妈妈用不到

🚫 常见误区

  • ❌ "懒癌不用管" → 有转移必须规范治
  • ❌ "淋巴结转移=晚期没救" → 很常见，Ⅱ期治愈率仍高
  • ❌ "切了终身吃药可怕" → 优甲乐便宜安全，每天一片
  • ✅ 关键在找对医生做规范彻底的首台手术

  • 合并症多，建议多学科会诊（MDT）：外科 + 麻醉科 + 心内科 + 神经内科 + 呼吸科
  • 提前与医生确认「是不是您本人主刀」+ 排床时间

⏱️ 术前时间线参考

拿到病理 → 挂专家定手术（1 周内）→ 双抗停药 + 血压/心率/甲功准备（1–2 周）→ 术前全套检查 + 麻醉评估（住院前 3–7 天）→ 手术。

🗣️ 不会说普通话，住院怎么办

南阳话属中原官话，医护日常能懂六七成。真正的风险只在三个瞬间：术后憋气（血肿）、手麻（低钙）、术前谈话听不懂。

  • 1入院当天到护士站要护工，明说「要一对一、最好会河南话的阿姨」。东肿默认一对多管好几床，不主动提就排一对多。
  • 2床头贴大字沟通卡：写清「只会河南方言，请说慢一点」+ 诊断 + 过敏 + 家属电话（可打印版见 2026-10-23-床头沟通卡.html）。
  • 3教她 5 句 + 手势：疼 / 手麻 / 喘不上气 / 恶心 / 要上厕所；说不清就指床头卡。
  • 4手机充满电 + 充电宝，微信置顶，教她按一下就能视频。
  • 5术前谈话必须家属到场（东肿在 8 号楼 11 层），这是唯一能完整了解手术范围和风险的机会。
  • 6申请陪护的话术：别说「我们想陪」，要说「脑梗后遗言语不利 + 生活自理受限 + 跌倒风险，需要陪护」——护士长认这个。

☎️ 入院前必打：病区护士站三问（打病区，不是总机）

「我妈 60 岁，甲状腺癌要做全切加左颈淋巴结清扫，有脑梗后遗症、只会说方言、生活自理能力受限，请问：

🎯 重疾界定：Ⅰ期=轻症，Ⅱ期=重疾

🏥 特需部报销规则

  • 挂号费（含特需挂号费）：不报——保单费用清单里没有"挂号费"这项
  • 一般医疗只报普通部；未买特需加油包，普通疾病去特需部不报
  • 确诊重大疾病后：特需部/国际部/VIP部 0免赔、100%赔付，特需部不支持社保结算仍 100%
  • 床位费限 2,500元/天、陪床费限 1,000元/天

📅 住院前后 30 天门急诊（可报）

确诊重疾 + 住院手术后，住院前 30 天 ~ 出院后 30 天内、与住院同因的门急诊费用（含特需门诊检查费/诊疗费）可走「重大疾病住院前后门急诊」报销。条件：①确诊重疾 ②因该病住院 ③住院前30天内 ④与住院同因。

⚠️ 关键前提（已确认无风险）：保单"高危结节（4级及以上结节）"属特定既往症除外。妈妈最早的甲状腺记录是 2026-05-04（TI-RADS 4a），在投保日 2026-03-20 之后 → 属投保后新发，甲状腺癌可按"新发恶性肿瘤"正常赔付。

❤️ 高血压/脑梗的连带风险

妈妈高血压3级+脑梗属特定既往症（"高血压及全部并发症不在保障范围"）。甲状腺癌手术本身能报，但术中/术后若出现高血压、脑梗相关并发症（如脑血管意外），那部分费用可能被除外。术前务必控制好血压、评估脑血管风险。
